# SkyX Landing Page

1. Extraia o arquivo ZIP.
2. Abra a pasta extraída no VS Code.
3. Abra o terminal do VS Code.
4. Execute `npm install`.
5. Execute `npm run dev`.
6. Abra o endereço mostrado no terminal.

## Onde editar

- Página e textos: `src/App.tsx`
- Cores e estilos: `src/index.css`
- Imagem principal: `public/hero-car.png`

Os números de telefone, e-mail e links atuais são provisórios.
